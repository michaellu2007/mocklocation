# beagleincampus 0.0.2 上手说明（路线收集版）

这是一个校园跑路线模拟工具（个人使用/学习），当前版本的核心目标：
**画出你的校园跑步路线并发给作者**，帮我们积累真实路线库。

## 一、安装后的一次性设置（很重要，跳过无法模拟）

1. 手机「设置 → 更多设置 → 开发者选项」：
   - 打开「USB 调试」不需要，但要找到 **「选择模拟位置信息应用」**，选中 **MockRun**
2. 首次点「开跑」时按提示允许 **定位权限**（精确+粗略都要允许）

没授权的表现：点开跑会提示"请先在开发者选项中把本应用设为模拟位置信息应用"。

## 二、画出你的跑步路线

1. 主界面模式选 **「自定义」** → 点「**绘制路线**」
2. 在地图上**沿你的跑步路线依次点按**加途经点（起点、弯道、终点……）
   - 勾选「环线(跑回起点)」表示跑一圈回到起点（校园跑一般是环线）
   - 底部会显示点数和大约长度；「撤销」回退上一个点
3. 点「**保存并使用**」→ 自动存入「我的路线」并回到主界面

## 三、试跑

- 主界面点「**开跑**」，通知栏出现"比格正在跑"
- 打开任意地图/运动 App 验证位置是否在路线上移动
- 「停止」随时结束

> 注：当前版本高德 key 未配置时地图是空白网格，不影响画点和试跑；
> 想看底图请告知作者你的设备信息，等下一版内置 key。

## 四、把路线发给作者（本版本的核心任务）

「我的路线」→ 点你的路线 → 「**分享给作者**」→ 选微信/QQ → 发给作者。
导出的 `.json` 文件就是完整路线，作者导入后即可收录。

## 五、已知边界（0.0.1 毛坯）

- 地图瓦片可能空白（key 未配），画点功能不受影响
- 速度滑条 0.1~6.0 m/s，配速实时显示
- 暂停/继续、运动中比格动画等在后续版本
