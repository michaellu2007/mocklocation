## 工作原理（为什么不需要 root）

Android 为开发者提供了官方的模拟位置能力：在「开发者选项 → 选择模拟位置信息应用」中授权后，应用即可通过 `LocationManager.addTestProvider` / `setTestProviderLocation` 向系统注入坐标，所有消费定位的 App 读到的就是注入后的位置。整个过程走的是系统公开 API，**不修改任何系统文件、不注入任何进程，所以不需要 root**。

代价是诚实的：系统会在分发给消费方的位置上强制打上 `isMock=true` 标记（Android 12+），读取该标记的 App 能识别"这是模拟位置"。本应用选择正视它，而不是隐藏它。

## 核心设计：双通道轨迹模拟

真实 GPS 不是一条数学曲线——它有漂移、有抖动、有速度起伏。本项目把"显示"与"注入"分成两条独立通道（参考 LocationSpoofer 的分离式架构）：

- **显示通道**：App 自己地图上的回放点是**零噪声的理想轨迹**，永远贴着路线中心线；
- **注入通道**：交给系统 TestProvider 的定位，在理想轨迹之上叠加**有界扰动**——基准由 `速度 × 时间` 干净推进，扰动永不反馈进位置状态，因此**不存在误差累计跑偏**。

### 📈 有界 OU 扰动（Ornstein-Uhlenbeck 随机过程）

```
X(t+dt) = clamp( X(t) + σ·√dt·N(0,1) − α·X(t)·dt )
```

- `σ·√dt·N(0,1)`：布朗运动增量。高斯白噪声的频谱是平坦的，**FFT 频谱分析找不到单频峰**——合成正弦波一查一个准，白噪声查不出来；
- `−α·X(t)·dt`：均值回归项。真实 GPS 的滤波器会把异常漂移慢慢拉回原位，配合硬钳幅（±4.4m），偏移**永远有界**；
- σ ≈ 0.2m、α = 0.05/s、稳态游走 ±0.7m——肉眼是"活的"，幅值上不撒谎。

同一框架下还有三条独立的低频波动：**Accuracy**（2.2m 基准微起伏，1.5~3.5m 限幅）、**Altitude**（对流层延迟，垂直方向波动更大）、**瞬时速度**（±0.11 m/s，真实移动的瞬时速率从来不是常数）。

### 🐾 步频横向抖动（可独立开关）

每一步落地时，身体都会垂直于前进方向轻微左右偏摆。算法给轨迹叠加**垂直于航向的高斯白噪声横移**（标准差约 0.15m），让轨迹放大看有"一步一晃"的质感。设置页可单独关闭。

参数集中在 `RoutePlayer.kt` 的 `TUNING` 对象里，嫌大嫌小改一个数字；显示/注入的分离见 `cleanMotion()`。

## 功能

- 🗺️ **双引擎地图**：高德 / 百度（设置中切换），普通/卫星图
- 🔍 **搜索选点**：输入地名直达，不用在图上瞎摸
- ✏️ **准星描点**：屏幕中心十字 + 大号「＋」，平移按一下收一个点，自己画路线；逐点序号标记（起绿·终红）
- 🐾 **路线回放**：小蓝点 10Hz 沿线平滑推进，镜头跟随；开跑自动把整条路线框进屏幕
- 🚀 **速度配速**：0.1~10.0 m/s，实时换算配速
- 🔁 **跑完行为**：从头循环 / 跑完暂停，路线页勾选
- 🎲 **波动开关**：波动总开关（像真人 / 绝对精准）+ 步幅抖动独立开关
- 🧭 **应用坐标系**：手动输入坐标按 WGS-84 / GCJ-02（高德）/ BD-09（百度）口径解析，自动转 WGS-84 注入
- 💾 **路线库**：自定义路线保存、导出 JSON、分享、导入
- 🔑 **个人 Key**：高德 Key 由用户自行申请填入（页面内提供包名与本机 SHA1 一键复制），公共 Key 仅供试用
- 🐕 **比格全家桶**：启动页奔跑动画（二帧循环）、爪印常驻通知
