# MockRun 🐶 —— 校园跑路线模拟（个人学习项目）

> 一只小比格替你在校园里跑步。基于 Android 系统开放的 **模拟位置（TestProvider）** 机制，**无需 root**。

## 工作原理（为什么不需要 root）

Android 为开发者提供了官方的模拟位置能力：在「开发者选项 → 选择模拟位置信息应用」中授权后，应用即可通过 `LocationManager.addTestProvider` / `setTestProviderLocation` 向系统注入坐标，所有消费定位的 App 读到的就是注入后的位置。整个过程走的是系统公开 API，**不修改任何系统文件、不注入任何进程，所以不需要 root**。

代价是诚实的：系统会在分发给消费方的位置上强制打上 `isMock=true` 标记（Android 12+），读取该标记的 App 能识别"这是模拟位置"。本应用选择正视它，而不是隐藏它。

## 核心算法：让比格跑得像真狗

真实 GPS 不是一条数学曲线——它有漂移、有抖动、有速度起伏。MockRun 用两个算法叠加模拟：

### 🐾 比格步频算法（步态横向摆动）

每一步落地时，身体都会垂直于前进方向轻微左右偏摆。算法以步频节拍给轨迹叠加**垂直于航向的高斯白噪声横移**（标准差约 0.10m）：走路摆幅小而密，跑步摆幅大而疏。它让轨迹在放大到楼栋级别时呈现出"一步一晃"的质感，而不是几何课上的直线。

### 📈 SDE 漂移算法（Ornstein-Uhlenbeck 随机过程）

漂移建模为一条**随机微分方程（SDE）**：

```
X(t+dt) = X(t) + σ·√dt·N(0,1) − α·X(t)·dt
```

- `σ·√dt·N(0,1)`：布朗运动增量。高斯白噪声的频谱是平坦的，**FFT 频谱分析找不到单频峰**——合成正弦波一查一个准，白噪声查不出来；
- `−α·X(t)·dt`：均值回归项（α = 0.10/s）。真实 GPS 的滤波器（卡尔曼之流）会把异常漂移慢慢拉回原位，这一项让漂移**有界**：跑步档稳态标准差约 2 米，偶尔飘到 ±6 米，但绝不会越飘越远触发"位置跳变"告警。

同一套框架下还有三条独立的低频漂移：**Accuracy**（GDOP 波动，2~50m 限幅）、**Altitude**（对流层延迟，垂直方向波动更大）、**瞬时速度**（±0.11 m/s，真实跑者的配速从来不是常数）。

三 algo 叠加的效果：放大看有毛孔，缩小看是狗。参数集中在 `RoutePlayer.kt` 的 `TUNING` 对象里，嫌大嫌小改一个数字。

## 功能

- 🗺️ **双引擎地图**：高德 / 百度（设置中切换），普通/卫星图
- 🔍 **搜索选点**：输入地名直达，不用在图上瞎摸
- ✏️ **准星描点**：屏幕中心十字 + 大号「＋」，平移按一下收一个点，自己画路线；逐点序号标记（起绿·终红）
- ⭕ **预设环线**：标准操场 400m（双直道双半圆）/ 1km / 2km / 3.5km，锚点随意
- 🚀 **速度配速**：0.1~6.0 m/s，实时换算配速
- 🎲 **波动模拟开关**：设置里一键切换"像真人 / 绝对精准"
- 🧭 **应用坐标系**：手动输入坐标按 WGS-84 / GCJ-02（高德）/ BD-09（百度）口径解析，自动转 WGS-84 注入
- 💾 **路线库**：自定义路线保存、导出 JSON、分享给作者、导入他人路线
- 🔑 **个人 Key**：高德 Key 由用户自行申请填入（页面内提供包名与本机 SHA1 一键复制），公共 Key 仅供试用
- 🐕 **比格全家桶**：桌面图标、启动奔跑动画（二帧循环）、地图上随航向转身的小比格、爪印通知
